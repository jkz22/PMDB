# Imported harmonisation pipelines (N4 + Nyúl–Udupa, BaSiC)

A third preprocessing route next to the LUT route (`docs/harmonisation.md`) and the physics route
(`docs/clean.md`). Nothing here is PMDB-specific except the input: the two pipelines below are taken
from the literature and run **as implemented in their open-source packages**, on half-resolution grey
levels, with the exclusion mask of the clean pipeline ("the crops": border/colour-marker columns,
uncorrectable scan bands, charging, 0/255 clipping) weighted out of every fit. No in-house pore/graphite
anchors, LUTs, dark-level or flat-field estimates are used.

| route | what it does | source | implementation |
|---|---|---|---|
| `nyul` | N4ITK bias-field correction, then Nyúl–Udupa piecewise-linear histogram standardisation onto a standard scale learned from the labelled sites | Tustison et al., *N4ITK: improved N3 bias correction*, IEEE TMI 29(6) 2010, doi:10.1109/TMI.2010.2046908; Nyúl, Udupa & Zhang, *New variants of a method of MRI scale standardization*, IEEE TMI 19(2) 2000, doi:10.1109/42.836373; Reinhold et al., *Evaluating the impact of intensity normalization on MR image synthesis*, SPIE MI 2019, doi:10.1117/12.2513089 (the `intensity-normalization` package) | `SimpleITK.N4BiasFieldCorrectionImageFilter`, `intensity_normalization.normalize.nyul.NyulNormalize` |
| `basic` | BaSiC: flat-field *S(x,y)*, dark-field *D(x,y)* and per-image baseline *bᵢ* from the whole collection (low-rank + sparse), image → *(I − D)/S − bᵢ* | Peng et al., *A BaSiC tool for background and shading correction of optical microscopy images*, Nature Communications 8, 14836 (2017), doi:10.1038/ncomms14836 | `basicpy.BaSiC` (v2, PyTorch backend) |

Why these two: a literature search (Crossref, GitHub) found no SEM-specific intensity-harmonisation
package – SEM papers on charging, drift and multi-session imaging describe ad-hoc brightness/contrast
matching without released code. The two reproducible, widely used pipelines for "same material, different
acquisition" are the neuroimaging multi-scanner recipe (bias-field correction + histogram standardisation,
e.g. Shinohara et al., *NeuroImage: Clinical* 2014) and the microscopy shading/drift tool BaSiC
(a modern successor of CIDRE, Smith et al., *Nature Methods* 2015). Both are imported unchanged.

## Build and load

```bash
python scripts/build_clean.py --workers 4 --out outputs/clean            # masks (once; see docs/clean.md)
python scripts/build_clean.py --data-root data_heldout --out outputs/clean_heldout --targets outputs/clean/targets.json --workers 3
python scripts/build_harmonise_ext.py                                    # both methods, labelled + held-out (~6 min)
python scripts/eval_harmonise_ext.py                                     # metrics + figures → outputs/harmonisation_ext/
```

```python
from pmdb.harmonise_ext import load_ext
from pmdb import clean
img, mask = load_ext("Batch_3", "71vgq3fw", method="nyul")   # img (H, W, 3) uint8 [BSE, Inlens, SE_type], mask (H, W, 3) uint16
valid = clean.valid_for_stats(mask[..., 0])                  # always mask; pixels under the mask hold real, unfilled values
```

Coordinates are those of `load_clean(..., resolution="half")` (50 nm/px, no 4-px column crop – border
pixels are flagged `BIT_BORDER` instead), so the arrays line up with the physics route, not with
`cache/half`. Models are fitted on the 31 labelled sites only (`cache/harmonised_ext/<method>/model.json`)
and applied unchanged to the held-out sites (`cache_heldout/harmonised_ext/`); the held-out images never
enter the standard scale or the flat-field.

Storage: `image` is uint8 after a fixed re-scaling recorded in `manifest.csv` (`store_gain`, `store_offset`):
`nyul` output is already on a 0–255 standard scale; `basic` output is raw − bᵢ (mean-centred grey), stored
as `+64` so that negative values survive. `load_ext(..., as_uint8=False)` undoes it. Per-site parameters
(Nyúl landmarks, N4 bias range, BaSiC baselines, clipped fraction) are in `params.csv`.

## Parameters (package defaults unless stated)

* N4: 4 fitting levels × 50 iterations, B-spline default (4 control points), fitted at 4× shrink on
  valid pixels, +1 grey-level offset because N4 works in log space and 0 is a legal BSE value.
* Nyúl: landmarks at 1, 10, 20, …, 90, 99 % (package default), standard scale 0–255, landmarks of each
  image computed on its valid pixels, mapping applied to all pixels (masked ones keep no special treatment).
* BaSiC: `get_darkfield=True`, `smoothness_flatfield = smoothness_darkfield = 1`, approximate mode, 10
  reweighting iterations; collection resampled to a common 256 × 896 working grid (sites differ in height);
  fields resampled back to each site's grid; baseline from `fit_only_baseline` (time-lapse mode).

## Results

See `outputs/harmonisation_ext/REPORT.md` (regenerated by `scripts/eval_harmonise_ext.py`) and the
figures there: `effects_examples.png` (strong / mild / clean / Batch-1 / held-out site before and after), `effects_<detector>.png` (every site raw | nyul | basic with the mask overlaid),
`crops_gallery.png` (what is cut out of the poorly imaged fields and why), `hist_by_method.png`,
`black_level_by_method.png`, `fractions_by_method.png`.

Headline numbers (31 labelled sites; `none` = raw grey at the same coordinates, `hybrid` = in-house LUT route; all
anchors, segmentation thresholds and percentiles are computed on the stats-valid pixels of each detector only):

| metric | none | nyul | basic | hybrid |
|---|---|---|---|---|
| BSE black-level gap, 4 strong Batch-3 sites − rest of Batch 3 (grey) | 22.0 | 0.0* | 15.8 | 1.2 |
| SE_type black-level gap (grey) | 19.3 | 0.0* | 10.8 | 0.3 |
| BSE p90−p10 width gap strong − rest (gain artefact, grey) | −9.3 | 0.0* | −9.1 | 3.9 |
| Si/graphite contrast ratio, relative change on Batch 1/2 sites | 0 | 0.072 | 0.008 | 0.003 |
| across-site SD of the contrast ratio (material spread kept?) | 0.199 | 0.129 | 0.199 | 0.196 |
| fixed-threshold Si-fraction gap strong − rest | 0.016 | 0.008 | 0.002 | 0.026 |
| fixed-threshold vs segmenter Si fraction, r | 0.94 | 0.69 | 0.95 | 0.91 |
| shortcut batch classifier (grey statistics only), LOO accuracy | 0.61 | 0.65 | 0.55 | 0.55 |
| shortcut strong-vs-rest within Batch 3 | 1.00 | 0.94 | 1.00 | 1.00 |

\* by construction: Nyúl maps every site's 1st/99th percentile to 0/255 and its 10…90 % landmarks to the
common standard scale, so percentile-based gaps are exactly zero and 1 % of the pixels are clipped at
each end of the stored range.

What this says:

* **Nyúl–Udupa** removes the Batch-3 offset *and* gain, as histogram standardisation must, but it does
  so by forcing the percentile positions of every site to coincide: the Si/graphite contrast of clean
  sites moves by 7 %, the across-site spread of material contrast shrinks (0.199 → 0.129), and the
  fixed-threshold Si fraction no longer tracks the segmenter (r 0.94 → 0.69) because a site with more Si
  has its bright landmarks pulled down. The grey statistics still identify the batch about as well as
  before (0.65 vs 0.61 LOO accuracy) – the standardised histograms differ in *shape* between landmarks.
  This is the documented behaviour of the method on images whose tissue/phase composition differs
  (Nyúl et al. 2000 assume the same composition in every scan); it is the imported pipeline, not a bug.
* **BaSiC** fits a dark-field of exactly zero and a flat-field within ±2 % on BSE/SE_type (±16 % on
  Inlens, i.e. a real large-scale brightness gradient), so its correction reduces to the per-image
  baseline *bᵢ*. Because the strong sites' +22 offset is largely compensated by their 0.69× gain at the
  mean grey, *bᵢ* barely differs between groups and the black-level gap only falls from 22 to 16; the
  gain is untouched. BaSiC leaves material contrast essentially untouched (0.8 % change) – it simply
  does not model this artefact.
* Neither imported pipeline removes the strong-site imaging fingerprint (strong-vs-rest classifier
  0.94–1.00); the LUT route (`hybrid`/`affine2`) and the physics route (`docs/clean.md`) remain the
  recommended inputs. These two routes are kept for ablations as the "what the literature would do"
  baselines.

Held-out sites (`cache_heldout/harmonised_ext`): models fitted on labelled sites only; `xrv9xvzb` (mild
Batch-3 group, raw BSE p1 = 7) lands at p1 = 0 under `nyul` and keeps segmenter Si/pore fractions within
0.003 of the raw values under both methods (`outputs/harmonisation_ext/heldout_metrics.csv`).

## What is cropped and why

The only fixed crop is the border (`clean.BORDER_PX` = 8 full-res px, which covers the four
colour-marker columns of the raw TIFFs). Everything else is *masked, not cropped*: the arrays keep
their full extent and the mask says which pixels are unusable and why (`clean.BIT_NAMES`). **No field in
`data/` or `data_heldout/` shows a Cu collector or the coating's free surface** – all 34 images are
interior crops of the coating (`collector_found = free_surface_found = False` in
`outputs/clean*/summary.csv`), consistent with `docs/data-processing.md`. The detectors exist and are
tested on phantoms, so if a future field does include the collector, it will be masked
(`BIT_COLLECTOR`) and shown in `crops_gallery.png` automatically. What *is* excluded in the current data
is listed in `outputs/harmonisation_ext/crops_table.csv` (per site/detector fraction by reason).
